# הגדרת סכמה ואימות

## סקירת Schema

JSON Schema מגדיר:
- **מבנה הנתונים**: אילו שדות צריכים להיות
- **סוג הנתונים**: מחרוזת, מספר, תאריך, וכו'
- **כללי אימות**: אורך, תבנית, טווח ערכים
- **שדות חובה**: אילו שדות חייבים להופיע

המערכת משתמשת בתקן JSON Schema 2020-12 לאימות נתונים.

---

## יצירת סכמה חדשה

### דרך 1: תבנית מוכנה

1. עבור ללשונית "סכמה" בטופס מקור הנתונים
2. לחץ "השתמש בתבנית"
3. בחר תבנית:

| תבנית | שדות עיקריים |
|--------|-------------|
| **לקוח ישראלי** | ת"ז, טלפון, כתובת, שם |
| **עסקה פיננסית** | סכום, תאריך, סוג עסקה |
| **קטלוג מוצרים** | שם, מחיר, מלאי |
| **רשומת עובד** | שם, תפקיד, משכורת |
| **חשבונית מע"מ** | מספר, תאריך, סכום, מע"מ |

4. התאם אישית לפי הצורך
5. שמור סכמה

### דרך 2: עורך חזותי

1. לחץ "צור סכמה חדשה"
2. מלא פרטים בסיסיים:
   - **שם סכמה**: שם טכני באנגלית (lowercase, underscores)
   - **שם תצוגה**: שם בעברית
   - **תיאור**: הסבר מה סכמה זו מאמתת

3. הוסף שדות:
   - לחץ "הוסף שדה"
   - **שם שדה**: שם באנגלית (לדוגמה: `customer_id`)
   - **שם תצוגה**: שם בעברית (לדוגמה: "מספר לקוח")
   - **סוג**: בחר מהרשימה
   - **חובה**: סמן אם השדה הוא חובה

4. הגדר אימותים לכל שדה:

**עבור מחרוזת (String):**
- אורך מינימלי/מקסימלי
- תבנית Regex (לדוגמה: ת"ז ישראלית, מספר טלפון)
- פורמט (email, uri, date-time)

**עבור מספר (Number):**
- ערך מינימלי/מקסימלי
- כפולה של (multipleOf)

**עבור תאריך:**
- פורמט: date, date-time, time
- טווח תאריכים

**עבור boolean:**
- ערכים: true/false

5. שמור סכמה
6. ניתן לקשר סכמה למקור נתונים

---

## עריכת סכמה קיימת

1. ברשימת סכמות, לחץ "ערוך"
2. ערוך שדות או אימותים
3. שמור שינויים

:::warning שים לב
שינוי סכמה משפיע על קבצים עתידיים בלבד. קבצים שכבר עובדו לא מושפעים.
:::

## סכמה אוטומטית מייבוא

בעת [ייבוא מקובץ](./import-from-file), המערכת מייצרת סכמה אוטומטית על סמך הנתונים שזוהו:

- **זיהוי סוגי שדות**: integer, number, boolean, date, string
- **תבניות חכמות**: דוא"ל, מספר טלפון, פורמטים של תאריך
- **מפריד CSV**: זיהוי אוטומטי של פסיק, נקודה-פסיק, Tab

הסכמה שנוצרת ניתנת לעריכה ידנית בעורך Monaco לפני ואחרי יצירת מקור הנתונים.

---

## כללי אימות

כאשר קובץ מעובד, כל רשומה נבדקת מול הסכמה:

- **רשומה תקינה**: עוברת ליעד הפלט
- **רשומה שגויה**: תלוי בהגדרת "פעולה בעת שגיאה":
  - **המשך עיבוד**: רשומות תקינות ממשיכות, שגויות נשלחות ל"רשומות לא תקינות"
  - **הפסק עיבוד**: כל הקובץ נדחה
  - **אחוז מקסימלי**: אם אחוז השגיאות עובר את הסף, העיבוד נעצר

## עזרת Regex

עורך הסכמה כולל כלי עזרה לביטויי Regex עם תבניות נפוצות:

| תבנית | Regex | דוגמה |
|--------|-------|--------|
| ת"ז ישראלית | `^\d{9}$` | 123456789 |
| טלפון ישראלי | `^0\d{1,2}-?\d{7}$` | 03-1234567 |
| דוא"ל | `^[\w.-]+@[\w.-]+\.\w+$` | user@example.com |
| תאריך (DD/MM/YYYY) | `^\d{2}/\d{2}/\d{4}$` | 25/03/2026 |
