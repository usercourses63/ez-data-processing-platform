Append 3 new tests after the existing SANITY-07 test block in `src/Frontend/tests/e2e/sanity.spec.ts`:

1. Add a `DOCS_URL` constant at the top (near the other URL constants): `const DOCS_URL = process.env.DOCS_URL || 'http://localhost:30800';`

2. **SANITY-08** — `@Sanity SANITY-08: Docs homepage opens and contains expected content`:
   - Use `{ page }` fixture (not apiContext -- this needs a real browser)
   - `const response = await page.goto(DOCS_URL + '/docs/');`
   - Assert `response?.status()` is 200
   - `const content = await page.textContent('body');`
   - Assert `content` matches `/ez|documentation/i` (case-insensitive)

3. **SANITY-09** — `@Sanity SANITY-09: Hebrew user guide loads with Hebrew content`:
   - Use `{ page }` fixture
   - `const response = await page.goto(DOCS_URL + '/docs/user-guide-he');`
   - Assert `response?.status()` is 200
   - `const content = await page.textContent('body');`
   - Assert `content` matches `/[\u05D0-\u05EA]/` (Hebrew character range)

4. **SANITY-10** — `@Sanity SANITY-10: Frontend Help button navigates to docs`:
   - Use `{ page }` fixture
   - `await page.goto(FRONTEND_URL);` (uses existing FRONTEND_URL constant = http://localhost:7000)
   - Locate help button: `page.locator('button[aria-label="Open user guide"], button[aria-label="פתח מדריך למשתמש"]')`
   - Assert button is visible with `await expect(helpButton).toBeVisible();`
   - Capture popup: `const [popup] = await Promise.all([page.waitForEvent('popup'), helpButton.click()]);`
   - `await popup.waitForLoadState();`
   - Assert `popup.url()` contains `:30800`

Important: SANITY-10 uses `page.waitForEvent('popup')` because `openDocsInNewTab` calls `window.open()` which creates a new browser tab/window, NOT a navigation on the current page. Using `page.url()` after click would still show the frontend URL.
