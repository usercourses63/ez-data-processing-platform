Create `scripts/sanity-test.sh` with the following exact implementation:

**Header and setup:**
```
#!/bin/bash
set -euo pipefail
```
- `SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"`
- `REPO_ROOT="$(cd "$SCRIPT_DIR/.." && pwd)"`
- `NAMESPACE="ez-platform"`
- Accept optional arg `$1` for package directory path

**Step 1 - Auto-detect deployment package:**
- If `$1` is provided, use it as `PKG_DIR`
- Otherwise, `PKG_DIR=$(ls -dt "$REPO_ROOT"/dist/deployment-*/ 2>/dev/null | head -1)`
- If empty, print: `"ERROR: No deployment package found in dist/"`, `"Run these commands first:"`, `"  bash scripts/build-all-images.sh"`, `"  bash scripts/assemble-package.sh"`, then `exit 1`
- Verify `$PKG_DIR/images/services` directory exists, error if not

**Step 2 - Cleanup trap:**
- `PIDS=()` array for background process tracking
- `cleanup() { for pid in "${PIDS[@]}"; do kill "$pid" 2>/dev/null || true; done; }`
- `trap cleanup EXIT`

**Step 3 - Delete namespace:**
- `echo "==> Deleting namespace $NAMESPACE..."`
- `kubectl delete namespace "$NAMESPACE" --ignore-not-found --timeout=120s --wait=true`

**Step 4 - Remove cached application images from minikube:**
- `echo "==> Removing cached ez-platform images from minikube..."`
- Loop: `for img in $(minikube image ls 2>/dev/null | grep "ez-platform/" || true); do`
- `minikube image rm "$img" 2>/dev/null || true`
- `done`

**Step 5 - Load service images (parallel):**
- `echo "==> Loading service images into minikube (parallel)..."`
- `LOAD_PIDS=()`
- `for tar in "$PKG_DIR"/images/services/*.tar; do`
- `[ -f "$tar" ] && { echo "  Loading $tar ..."; minikube image load "$tar" & LOAD_PIDS+=($!); }`
- `done`
- Wait and check: `for pid in "${LOAD_PIDS[@]}"; do wait "$pid" || { echo "ERROR: image load failed"; exit 1; }; done`

**Step 6 - Load infrastructure images (parallel):**
- Same pattern for `"$PKG_DIR"/images/infrastructure/*.tar`
- Skip silently if directory does not exist or is empty

**Step 7 - Helm deploy:**
- `echo "==> Deploying via Helm..."`
- `helm upgrade --install ez-platform "$REPO_ROOT/helm/ez-platform" --namespace "$NAMESPACE" --create-namespace --values "$REPO_ROOT/helm/ez-platform/values-local.yaml" --wait --timeout 15m`

**Step 8 - Wait for pods:**
- `echo "==> Waiting for all pods to be Ready..."`
- `kubectl wait --for=condition=Ready pod --all -n "$NAMESPACE" --timeout=300s || { echo "Pod readiness timeout:"; kubectl get pods -n "$NAMESPACE"; exit 1; }`

**Step 9 - Start port-forwards (background):**
- `echo "==> Starting port-forwards..."`
- Array of port-forward commands (matching CI + docs):
  - `kubectl port-forward svc/datasource-management 5001:5001 -n "$NAMESPACE" &` + `PIDS+=($!)`
  - `kubectl port-forward svc/metrics-configuration 5002:5002 -n "$NAMESPACE" &` + `PIDS+=($!)`
  - `kubectl port-forward svc/validation 5003:5003 -n "$NAMESPACE" &` + `PIDS+=($!)`
  - `kubectl port-forward svc/scheduling 5004:5004 -n "$NAMESPACE" &` + `PIDS+=($!)`
  - `kubectl port-forward svc/invalidrecords 5007:5007 -n "$NAMESPACE" &` + `PIDS+=($!)`
  - `kubectl port-forward svc/fileprocessor 5008:5008 -n "$NAMESPACE" &` + `PIDS+=($!)`
  - `kubectl port-forward svc/output 5009:5009 -n "$NAMESPACE" &` + `PIDS+=($!)`
  - `kubectl port-forward svc/frontend 7000:8080 -n "$NAMESPACE" &` + `PIDS+=($!)`
  - `kubectl port-forward svc/docs 30800:80 -n "$NAMESPACE" &` + `PIDS+=($!)`
- `sleep 10` (allow port-forwards to establish)

**Step 10 - Seed with DemoDataGenerator:**
- `echo "==> Seeding cluster with DemoDataGenerator..."`
- `dotnet run --project "$REPO_ROOT/tools/DemoDataGenerator" -- --direct-connection --api-url http://localhost:5001`

**Step 11 - Ensure Playwright installed:**
- `echo "==> Ensuring Playwright chromium is installed..."`
- `cd "$REPO_ROOT/src/Frontend"`
- `npx playwright install chromium`

**Step 12 - Run sanity tests twice:**
- `echo "==> Running sanity tests (Run 1 of 2)..."`
- `RUN1_EXIT=0`
- `npm run test:e2e:sanity:headed || RUN1_EXIT=$?`
- `echo "==> Running sanity tests (Run 2 of 2)..."`
- `RUN2_EXIT=0`
- `npm run test:e2e:sanity:headed || RUN2_EXIT=$?`

**Step 13 - Print summary:**
- `echo ""`
- `echo "========================================"`
- `echo "  SANITY TEST RESULTS"`
- `echo "========================================"`
- `echo "Run 1: $([ $RUN1_EXIT -eq 0 ] && echo 'PASSED' || echo 'FAILED')"`
- `echo "Run 2: $([ $RUN2_EXIT -eq 0 ] && echo 'PASSED' || echo 'FAILED')"`
- `if [ $RUN1_EXIT -eq 0 ] && [ $RUN2_EXIT -eq 0 ]; then echo "OVERALL: PASSED"; else echo "OVERALL: FAILED"; fi`
- `echo "========================================"`
- `exit $(( RUN1_EXIT + RUN2_EXIT > 0 ? 1 : 0 ))`

**Part A: Create `scripts/sanity-test.ps1`**

Mirror the bash script logic in PowerShell idiom:

- `$ErrorActionPreference = "Stop"`
- `$ScriptDir = Split-Path -Parent $MyInvocation.MyCommand.Path`
- `$RepoRoot = Split-Path -Parent $ScriptDir`
- `$Namespace = "ez-platform"`
- `param([string]$PkgDir = "")` at top of script

**Auto-detect package:**
- If `$PkgDir` is empty, `$PkgDir = Get-ChildItem -Path "$RepoRoot\dist" -Directory -Filter "deployment-*" -ErrorAction SilentlyContinue | Sort-Object LastWriteTime -Descending | Select-Object -First 1 -ExpandProperty FullName`
- If still null/empty, `Write-Error "No deployment package found..."; Write-Host "Run: bash scripts/build-all-images.sh"; Write-Host "Run: bash scripts/assemble-package.sh"; exit 1`

**Namespace delete:**
- `kubectl delete namespace $Namespace --ignore-not-found --timeout=120s --wait=true`

**Remove cached images:**
- `$images = minikube image ls 2>$null | Where-Object { $_ -match "ez-platform/" }`
- `foreach ($img in $images) { minikube image rm $img 2>$null }`

**Load images (parallel with Start-Job):**
- Service images: `Get-ChildItem "$PkgDir\images\services\*.tar"` -> `Start-Job -ScriptBlock { minikube image load $using:tar }`
- Wait: `$jobs | Wait-Job | Receive-Job`
- Same for infrastructure images

**Helm deploy:**
- `helm upgrade --install ez-platform "$RepoRoot\helm\ez-platform" --namespace $Namespace --create-namespace --values "$RepoRoot\helm\ez-platform\values-local.yaml" --wait --timeout 15m`

**Wait pods:**
- `kubectl wait --for=condition=Ready pod --all -n $Namespace --timeout=300s`

**Port-forwards (background):**
- Use `Start-Process -WindowStyle Hidden kubectl -ArgumentList "port-forward -n $Namespace svc/datasource-management 5001:5001"` pattern (matching start-port-forwards.ps1 style)
- Include all 9 service port-forwards including docs: `svc/docs 30800:80`
- `Start-Sleep -Seconds 10`

**Seed:**
- `dotnet run --project "$RepoRoot\tools\DemoDataGenerator" -- --direct-connection --api-url http://localhost:5001`

**Playwright install:**
- `Set-Location "$RepoRoot\src\Frontend"`
- `npx playwright install chromium`

**Double run:**
- `$Run1Exit = 0; npm run test:e2e:sanity:headed; if ($LASTEXITCODE -ne 0) { $Run1Exit = $LASTEXITCODE }`
- `$Run2Exit = 0; npm run test:e2e:sanity:headed; if ($LASTEXITCODE -ne 0) { $Run2Exit = $LASTEXITCODE }`

**Summary:**
- Print results table, exit 0 only if both pass
- Cleanup: `taskkill /F /IM kubectl.exe 2>$null` in a try/finally or at end
