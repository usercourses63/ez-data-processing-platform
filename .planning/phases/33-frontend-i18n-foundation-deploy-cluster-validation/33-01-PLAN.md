## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Helm operator → Helm chart values | Operator-supplied `services.frontend.config.docsUrl` is interpolated into Deployment env, then container shell heredoc, then static HTML asset, then browser global. |
| minikube image store → kubelet | Locally-loaded image trust depends on `imagePullPolicy: IfNotPresent` matching the local tag exactly. Registry-prefix mismatches (docker.io vs bare) break this. |
| Browser → /config.js | Loaded synchronously before the React bundle; modifies `window.EZ_CONFIG`. |
| kubelet → pod port | Probes assume containerPort matches nginx listen port; mismatch causes silent rollout-hang. |
