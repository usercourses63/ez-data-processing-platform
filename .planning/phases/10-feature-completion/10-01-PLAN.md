2. Update Program.cs DI registration (if not already registered):
   - Ensure `services.AddSingleton<IArchiveService, SharpCompressArchiveService>();`

3. Add archive detection in file processing flow:
   - In the method that processes file content, add archive detection:
     ```csharp
     // After fetching file bytes
     if (_archiveService.IsArchive(fileName, fileBytes))
     {
         // Get archive settings from data source
         var extractionPattern = dataSource.ArchiveSettings?.ExtractionPattern ?? "*.*";
         var password = dataSource.ArchiveSettings?.Password;

         // Extract matching files
         var extractedFiles = await _archiveService.ExtractMatchingFilesAsync(
             fileBytes,
             extractionPattern,
             null, // auto-detect archive type
             password,
             ArchiveSecuritySettings.Default,
             cancellationToken);

         // Process each extracted file
         foreach (var (extractedPath, extractedContent) in extractedFiles)
         {
             await ProcessSingleFileAsync(dataSource, extractedPath, extractedContent, cancellationToken);
         }
         return;
     }

     // Non-archive file: process directly
     await ProcessSingleFileAsync(dataSource, fileName, fileBytes, cancellationToken);
     ```

4. Add logging for archive processing:
   - Log when archive detected: "Archive detected: {fileName}, extracting {count} files matching {pattern}"
   - Log each extracted file: "Processing extracted file: {extractedPath}"

5. Handle nested archives (if ArchiveSettings.ExtractNestedArchives is true):
   - Call ExtractMatchingFilesAsync recursively for nested archives
   - Respect max nesting depth from ArchiveSecuritySettings
