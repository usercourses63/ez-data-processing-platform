1. Update release-notes.md with v0.2.0 section at top:
   ```markdown
   ## v0.2.0 - External File Access (2026-02-XX)

   ### New Features

   #### NAS Device Management
   - **Dynamic NAS provisioning**: Configure NAS devices via Admin UI with automatic Kubernetes PV/PVC creation
   - **Role-based devices**: Assign Input, Output, Both, or Backup roles to NAS devices
   - **Mount status monitoring**: Real-time display of PV/PVC provisioning status
   - **Connection testing**: Verify NAS connectivity before provisioning

   #### Archive Extraction
   - **Multi-format support**: ZIP, TAR.GZ, RAR, 7Z archive extraction
   - **Pattern matching**: Extract specific files using glob patterns (e.g., *.csv)
   - **Nested archives**: Optional recursive extraction of archives within archives
   - **Security controls**: Zip bomb protection, max file size limits

   #### Enhanced Connection Tab
   - **NAS protocol**: Select NAS devices as file sources (replaces manual NFS configuration)
   - **Server-based configuration**: All protocols now use AdminServer configuration
   - **Archive settings**: Configure extraction options per data source

   ### API Changes

   #### New Endpoints
   - `GET /api/v1/nasdevices` - List NAS devices
   - `POST /api/v1/nasdevices` - Create NAS device
   - `PUT /api/v1/nasdevices/{id}` - Update NAS device
   - `DELETE /api/v1/nasdevices/{id}` - Delete NAS device
   - `POST /api/v1/nasdevices/{id}/provision` - Provision K8s resources
   - `POST /api/v1/nasdevices/{id}/test` - Test connection

   #### Changed Endpoints
   - `POST /api/v1/datasources` - Now accepts `nasDeviceId` for NAS protocol

   ### Configuration Changes

   #### New ConfigMap Keys
   None required - NAS devices configured via API

   #### Helm Values
   - `datasource-management.rbac.enabled`: Enable NAS device RBAC (default: true)

   ### Breaking Changes
   - NFS protocol removed from connection type dropdown (use NAS instead)

   ### Migration Guide

   #### From v0.1.1-rc3

   1. **Existing NFS data sources**: Must be reconfigured
      - Create NAS device in Admin > NAS Devices
      - Provision the device (creates PV/PVC)
      - Edit data source, change to NAS protocol, select device

   2. **Helm upgrade**:
      ```bash
      helm upgrade ez-platform ./helm/ez-platform -f values.yaml
      ```

   3. **RBAC verification**:
      ```bash
      kubectl get clusterrolebinding nas-device-manager-binding
      ```
   ```

2. Update changelog.md:
