  <name>Task 1: Create Docusaurus Dockerfile with version injection</name>
  <files>docker/Docusaurus.Dockerfile</files>
  <action>
Create docker/Docusaurus.Dockerfile for building the documentation portal:

```dockerfile
# Docusaurus Documentation Portal
# Multi-stage build with version injection

# Global ARGs
ARG NODE_VERSION=20
ARG VERSION=0.0.0
ARG COMMIT_SHA=unknown

# Build stage
FROM node:${NODE_VERSION}-alpine AS build
WORKDIR /app

# Redeclare ARGs for this stage
ARG VERSION
ARG COMMIT_SHA

# Copy package files
COPY release-package/docs-docusaurus/package*.json ./

# Install dependencies
RUN npm ci

# Copy source files
COPY release-package/docs-docusaurus/ ./

# Inject version into docusaurus.config.js
# Update the title line: title: 'EZ Platform v0.1.1-rc1' -> title: 'EZ Platform vX.X.X'
RUN sed -i "s/title: 'EZ Platform v[^']*'/title: 'EZ Platform ${VERSION}'/" docusaurus.config.js

# Debug: verify injection worked
RUN grep "title:" docusaurus.config.js

# Build Docusaurus site
RUN npm run build

# Production stage - Nginx
FROM nginx:alpine
WORKDIR /usr/share/nginx/html

# Redeclare ARGs for labels
ARG VERSION
ARG COMMIT_SHA

# OCI labels
LABEL org.opencontainers.image.version="${VERSION}"
LABEL org.opencontainers.image.revision="${COMMIT_SHA}"
LABEL org.opencontainers.image.title="EZ Platform Documentation"
LABEL org.opencontainers.image.description="Docusaurus documentation portal for EZ Platform"

# Remove default nginx static files
RUN rm -rf ./*

# Copy built Docusaurus site
COPY --from=build /app/build .

# Copy nginx configuration for SPA routing (use existing if present)
COPY release-package/docs-docusaurus/nginx.conf /etc/nginx/conf.d/default.conf

# Non-privileged port for OCP compliance
EXPOSE 8080

# Health check
HEALTHCHECK --interval=30s --timeout=3s --start-period=5s --retries=3 \
  CMD wget --quiet --tries=1 --spider http://localhost:8080/ || exit 1

CMD ["nginx", "-g", "daemon off;"]
```

Key patterns:
- npm ci instead of npm install for CI reproducibility (per research)
- sed injection for version in title (Pattern 3)
- Port 8080 for OCP compliance
- OCI labels for metadata
