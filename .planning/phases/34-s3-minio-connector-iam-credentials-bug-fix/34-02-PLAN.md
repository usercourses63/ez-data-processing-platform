<objective>
Guard A — write-only secret. Mask `SecretKey` in every AdminServer GET response so the plaintext (or even ciphertext) is never echoed back, and make update treat a masked/unchanged secret as "keep existing" rather than overwriting the stored secret with the mask sentinel.

Purpose: Honors SC-03's write-only requirement. Without masking, `ServersController.GetById`/`GetAll` return the raw `AdminServer` including `TypeSpecificConfig.SecretKey` — the secret appears in the browser network tab and the edit form re-posts the mask, clobbering the real secret (Pitfall 3).

Output: A masking helper applied across all five GET endpoints + a keep-existing-secret path in `ServerService.UpdateServerAsync`.
</objective>
