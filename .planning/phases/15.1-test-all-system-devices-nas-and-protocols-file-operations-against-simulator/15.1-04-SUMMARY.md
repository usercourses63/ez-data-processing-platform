## Decisions Made
- **File-based result persistence:** Each test file writes results to JSON temp file; teardown merges all files into final Markdown report. Solves Playwright worker isolation.
- **Main NFS server for all NAS tests:** Auxiliary NFS servers from simulator are alpine placeholders without real NFS. All NAS tests route through main NFS server (port 32149).
- **Hostname over IP:** Switched all test files from hardcoded `172.17.89.141` to `file-simulator.local` for maintainability.
- **Port injection in mount options:** `NasResourceService.BuildMountOptions()` now injects `port=<nodePort>` when NFS port differs from default 2049.
- **6 test failures accepted as infrastructure limitation:** ECONNREFUSED errors from port-forward disruption when NAS provisioning restarts DSM pod. System works correctly (verified manually).

## Issues Encountered
- **Port-forward disruption:** NAS provisioning triggers DSM pod restart, which breaks active port-forwards. 6 of 86 tests fail with ECONNREFUSED. This is a dev environment limitation (Hyper-V + port-forward), not a production issue. Verified manually that all operations work.
- **Alpine NFS placeholder servers:** Simulator's dynamic NFS servers are alpine containers without real NFS daemon. Resolved by routing all NAS tests through the main NFS server.
- **Multi-session execution:** Task 2 checkpoint required multiple debugging sessions across Feb 26 - Mar 16 to resolve NFS mount issues.
