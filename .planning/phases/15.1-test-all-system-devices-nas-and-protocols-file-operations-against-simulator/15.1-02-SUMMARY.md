## Decisions Made
- Credentials placed in TypeSpecificConfig with PascalCase keys (Username, Password) because ServerCredentials.FromBsonDocument extracts them using those exact key names from the BsonDocument
- FTP servers configured with PassiveMode: true in TypeSpecificConfig for NAT/firewall compatibility across Hyper-V clusters
- SFTP tests use /upload as the file operation base path, which is the standard SFTP chroot upload directory
- HTTP/WebDAV Scenario B explicitly documented as not applicable since the file-simulator has no POST /api/servers/http endpoint
- Dynamic device registration uses UI (addServerViaUI) with API fallback (createAdminServer) to ensure tests pass even if UI selectors change
