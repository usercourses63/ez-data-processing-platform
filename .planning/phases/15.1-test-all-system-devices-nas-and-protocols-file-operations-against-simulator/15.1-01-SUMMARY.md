## Decisions Made
- Used base64 encoding for file write content in the REST endpoint rather than multipart upload (simpler API, aligns with test use case where files are small)
- Credential resolution mirrors the existing ServerService.TestConnectionAsync pattern: try K8s secret resolver first, fall back to ServerCredentials.FromBsonDocument(TypeSpecificConfig)
- Generated XLSX file using raw ZIP construction in Node.js rather than adding xlsx/exceljs dependency (no new dependencies required)
- Protocol tests configured as sequential (fullyParallel: false) to avoid resource contention on shared simulator cluster
