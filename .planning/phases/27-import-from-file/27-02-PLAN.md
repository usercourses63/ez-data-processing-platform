2. Create `src/Frontend/src/utils/fileAnalyzer/archiveHandler.ts`:

   Export `ArchiveResult` interface:
   ```typescript
   export interface ArchiveResult {
     files: ArchiveFileEntry[];      // List of files in archive
     isEncrypted: boolean;           // Whether archive is password-protected
     archiveType: string;            // 'zip' | 'tar.gz' | 'rar' | '7z'
     extractFile: (filename: string, password?: string) => Promise<ArrayBuffer>;
   }

   export interface ArchiveFileEntry {
     name: string;                   // File path within archive
     size: number;                   // Uncompressed size in bytes
     isDirectory: boolean;
   }
   ```

   Export `handleArchive(file: File): Promise<ArchiveResult>`:
   - Determine archive type from extension (handle `.tar.gz` special case)
   - For `.zip` files: try JSZip first (`JSZip.loadAsync(await file.arrayBuffer())`)
     - If success: list files (filter out directories), return extractFile using `entry.async('arraybuffer')`
     - If error (likely encrypted): set `isEncrypted = true`, fall through to libarchive.js
   - For `.tar.gz`, `.rar`, `.7z`, and encrypted `.zip`: use libarchive.js
     - `Archive.open(file)` to open
     - `archive.getFilesObject()` to list entries
     - Return extractFile that calls `archive.extractFiles()` and returns the target file's ArrayBuffer
     - For encrypted archives: libarchive.js handles password via `Archive.open(file, { passphrase })` or equivalent API -- check the actual API during implementation
   - For encrypted `.rar` and `.7z`: per Research open question #2, if libarchive.js doesn't support them, return `isEncrypted = true` with an extractFile that throws a descriptive error asking user to extract manually

   Export `getDataFilesFromArchive(result: ArchiveResult): ArchiveFileEntry[]`:
   - Filter archive entries to only data files: `.csv`, `.json`, `.xml`, `.xlsx`
   - Exclude directories, hidden files (starting with `.`), `__MACOSX/` entries
   - Per D-16: if exactly 1 data file, it will be auto-selected by the UI; if multiple, UI shows selection

   Export `extractAndAnalyze(result: ArchiveResult, selectedFile: string, analyzeFileFn: (file: File) => Promise<any>, password?: string): Promise<any>`:
   - Extract the selected file as ArrayBuffer
   - Create a new `File` object from the ArrayBuffer with the selected file's name
   - Call `analyzeFileFn(newFile)` to run the standard file analysis pipeline
   - Add archive metadata to result: `isArchiveSource: true`, `archiveType`, `archivePassword: password || undefined`, `extractionPattern` derived from selectedFile name
  </action>
