2. Create `CsvToJsonConverterHeaderlessTests.cs` covering IMPORT-06:

   **Test: Headed CSV with metadata produces normal output (backward compat)**
   - Create a CSV string with headers: "name,age,email\nAlice,30,alice@example.com\nBob,25,bob@test.com"
   - Create metadata: `{ "HasHeader": true }`
   - Call `ConvertToJsonAsync(stream, metadata)`
   - Parse JSON result, assert first record has keys "name", "age", "email"

   **Test: Headerless CSV with SchemaPropertyNames produces schema field names**
   - Create a CSV string WITHOUT headers: "Alice,30,alice@example.com\nBob,25,bob@test.com"
   - Create metadata: `{ "HasHeader": false, "SchemaPropertyNames": new string[] { "name", "age", "email" } }`
   - Call `ConvertToJsonAsync(stream, metadata)`
   - Parse JSON result, assert first record has keys "name", "age", "email" (NOT "Column1", "Column2", "Column3")
   - Assert values: name=Alice, age=30, email=alice@example.com

   **Test: Headerless CSV without SchemaPropertyNames falls back to Column1, Column2**
   - Create a CSV string WITHOUT headers: "Alice,30,alice@example.com"
   - Create metadata: `{ "HasHeader": false }`  (no SchemaPropertyNames)
   - Call `ConvertToJsonAsync(stream, metadata)`
   - Parse JSON result, assert first record has keys "Column1", "Column2", "Column3"

   **Test: No metadata defaults to HasHeader=true (backward compat)**
   - Create a CSV string with headers: "name,age\nAlice,30"
   - Call `ConvertToJsonAsync(stream)` with NO metadata (null)
   - Parse JSON result, assert first record has keys "name", "age"

   Each test creates a `CsvToJsonConverter` instance (via `new` or from DI), constructs a `MemoryStream` from the CSV text, calls `ConvertToJsonAsync`, and deserializes the JSON output to verify field names.
