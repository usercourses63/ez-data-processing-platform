<task type="auto">
  <name>Task 1: Pre-cleanup — wipe namespace and all stale PVs</name>
  <files></files>
  <action>
Simulate a clean OCP environment by removing all existing cluster state. Execute in order:

1. Kill any running kubectl port-forward processes:
   `taskkill /F /IM kubectl.exe 2>/dev/null || true`

2. Delete the ez-platform namespace (this deletes all namespaced resources — pods, pvcs, services, deployments, configmaps, secrets):
   `kubectl delete namespace ez-platform --ignore-not-found=true --timeout=120s`
   Wait for namespace deletion to complete: `kubectl get namespace ez-platform 2>&1` should return "not found".

3. Delete ALL cluster-scoped PVs that are not Bound (Released, Retained, Available, Failed). PVs survive namespace deletion and block new PVC binding if stale:
   ```
   kubectl get pv -o json | python3 -c "
   import sys, json
   pvs = json.load(sys.stdin)
   for pv in pvs['items']:
       phase = pv['status'].get('phase', '')
       name = pv['metadata']['name']
       if phase in ['Released', 'Retained', 'Available', 'Failed']:
           print(name)
   " | xargs -r kubectl delete pv --ignore-not-found=true
   ```
   If python3 is unavailable, use: `kubectl get pv --no-headers | awk '$5 ~ /Released|Retained|Available|Failed/ {print $1}' | xargs -r kubectl delete pv --ignore-not-found=true`

4. Also delete any PVs that have claimRef pointing to ez-platform namespace (handles edge cases):
   `kubectl get pv -o json | grep -l '"namespace": "ez-platform"' 2>/dev/null | xargs -r kubectl delete pv --ignore-not-found=true || true`

5. Verify cleanup: `kubectl get pv` should show no ez-platform PVs. `kubectl get namespace ez-platform` should return "not found".

Per D-01, D-02, D-03: This simulates a clean OCP deployment target — no shortcuts, no reuse of existing state.
  </action>
  <verify>
    <automated>kubectl get namespace ez-platform 2>&1 | grep -c "not found" && kubectl get pv --no-headers 2>/dev/null | grep -v "Bound" | grep -c "ez-platform" || echo "0 stale PVs"</automated>
  </verify>
  <done>Namespace ez-platform does not exist. No Released/Retained PVs remain. Cluster is in clean state ready for fresh install.</done>
</task>
