<task type="auto">
  <name>Task 1: NAS provisioning — provision all NAS devices from frontend UI</name>
  <files></files>
  <action>
Use Claude-in-Chrome extension to provision every NAS device through the Admin → NAS Devices UI. Per D-11, D-12, D-13: frontend ONLY, no API calls for provisioning.

Steps:
1. Navigate to the NAS Devices admin page:
   `mcp__claude-in-chrome__navigate` to `http://localhost:7000/admin/nas-devices`
   (or navigate to http://localhost:7000 and click Admin menu → NAS Devices)

2. Use `mcp__claude-in-chrome__get_page_text` to read the current page and identify how many NAS devices are listed and their current status (should all show as "Not Provisioned" or similar unprovisioned state).

3. For each NAS device in the list:
   a. Use `mcp__claude-in-chrome__find` to locate the Provision button for that device row
   b. Use `mcp__claude-in-chrome__javascript_tool` to click the Provision button:
      `document.querySelector('[data-testid="provision-btn-{id}"]')?.click()` or equivalent selector
   c. Wait for the status to change to "Provisioned" (poll with `mcp__claude-in-chrome__get_page_text` every 5 seconds, up to 60 seconds per device — NFS PVC binding takes time)
   d. Confirm the row shows "Provisioned" status before moving to the next device

4. After all devices show Provisioned: verify via READ-ONLY API call (this is allowed for verification, not provisioning):
   `curl -s http://localhost:5001/api/v1/nasdevices` — all records should show IsProvisioned=true

Per D-13: every NAS device must reach "Provisioned" state. If any fails, investigate in the browser (check error toast messages) before proceeding. Do NOT call the provision API directly as a workaround — that would be a bug to report, not a shortcut to take (D-12).
  </action>
  <verify>
    <automated>curl -s http://localhost:5001/api/v1/nasdevices | python3 -c "import sys,json; data=json.load(sys.stdin); items=data.get('Data',data) if isinstance(data,dict) else data; unprovisioned=[x for x in items if not x.get('IsProvisioned',True)]; print(f'{len(unprovisioned)} unprovisioned NAS devices remaining')"</automated>
  </verify>
  <done>All NAS devices show "Provisioned" status in the frontend UI. API confirms IsProvisioned=true for all records. No unprovisioned devices remain.</done>
</task>
