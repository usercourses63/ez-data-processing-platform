    {
        _logger.LogInformation("Monitoring client connected: {ConnectionId}", Context.ConnectionId);
        await base.OnConnectedAsync();
    }

    {
        if (exception != null)
            _logger.LogWarning(exception, "Monitoring client disconnected with error: {ConnectionId}", Context.ConnectionId);

PromQL instant queries (for KPIs):
- Throughput: `rate(business_records_processed_total[5m])` — sum result values
- Success rate: `1 - (rate(business_invalid_records_total[5m]) / rate(business_records_processed_total[5m])) * 100`
- Avg latency: `histogram_quantile(0.95, rate(business_processing_duration_seconds_bucket[5m]))` — convert to ms
- Active jobs: `business_active_jobs` — take value
- Queue depth: `sum(business_files_pending)` — take value
- Error rate: `rate(business_invalid_records_total[5m]) / rate(business_records_processed_total[5m]) * 100`

PromQL range queries (for time-series history — last 30 min, step 1m, yields ~30 data points):
Use `/api/v1/query_range` with `start={now-30m}&end={now}&step=60`.
- ThroughputHistory: `sum(rate(business_records_processed_total[5m]))` — map each `[timestamp, value]` to MetricDataPointDto
- LatencyHistory: `histogram_quantile(0.95, sum(rate(business_processing_duration_seconds_bucket[5m])) by (le))` — multiply by 1000 for ms
- ErrorHistory: `sum(rate(business_invalid_records_total[5m]))` — map each result to MetricDataPointDto

Parse Prometheus range response format: `result[0].values` is `[[timestamp, "value"], ...]` — convert each to MetricDataPointDto with `DateTime.UnixEpoch.AddSeconds(timestamp)` and `double.Parse(value)`. On failure return empty lists.

For alerts, query Prometheus alertmanager API: `GET /api/v1/alerts` — map to AlertDto. On failure return empty list.

For traces, query Jaeger HTTP API: `GET http://jaeger:16686/api/traces?service=DataProcessing.DataSourceManagement&limit=5&lookback=1h`. Map response to TraceDto. On failure return empty list. Use `configuration["Jaeger:Endpoint"] ?? "http://jaeger:16686"`.

All methods MUST have try/catch returning default/empty values on failure, with structured logging.

Private fields:

- `MonitoringInitialState? _latestState` with `object _stateLock` for thread-safe cache
- Public method `GetLatestState()` returns cached state (used by hub for initial state)

`ExecuteAsync` implementation:
```csharp
protected override async Task ExecuteAsync(CancellationToken stoppingToken)
{
    _logger.LogInformation("MonitoringBroadcaster started (health: {Health}s, infra: {Infra}s)",
        _healthInterval.TotalSeconds, _infraInterval.TotalSeconds);
    await Task.Delay(TimeSpan.FromSeconds(3), stoppingToken); // let services initialize

    var healthTask = RunHealthBroadcastLoop(stoppingToken);
    var infraTask = RunInfrastructureBroadcastLoop(stoppingToken);
    await Task.WhenAll(healthTask, infraTask);
}
```

`RunHealthBroadcastLoop` (5s): Creates scope, resolves `IDeviceHealthService`, calls `GetHealthStatusAsync()`, broadcasts via `_hubContext.Clients.All.SendAsync("DeviceHealthUpdate", data, ct)`. Updates `_latestState.DeviceHealth`.

`RunInfrastructureBroadcastLoop` (30s): Creates scope, resolves `IKubernetesMonitoringService`, `IPrometheusQueryService`, `IKafkaMonitoringService`. Calls each in parallel with `Task.WhenAll`. Broadcasts 6 events:
- `ServiceStatusUpdate` -> serviceStatuses
- `PodStatusUpdate` -> podStatuses
- `QueueStatusUpdate` -> queueStatuses
- `MetricsUpdate` -> dashboardMetrics
- `AlertUpdate` -> alerts
- `TraceUpdate` -> traces

Also updates `_latestState` with all data under lock. Maintains a rolling buffer `_recentPipelineEvents` (List of PipelineEventDto, max 50 items, newest first) that is populated by `AddPipelineEvent(PipelineEventDto)` public method. The method adds the event, trims to 50, and broadcasts `PipelineEventUpdate` via hub.

Each broadcast loop wraps the body in try/catch `(Exception ex) when (ex is not OperationCanceledException)` logging errors. Never lets exceptions break the loop.
