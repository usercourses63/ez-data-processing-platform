## State Transitions

### Data Flow States

| State | What User Sees | Data Source |
|-------|---------------|-------------|
| Initial load (SignalR connecting) | Spin loader, then data appears when InitialState event arrives | SignalR `InitialState` event on connect |
| Connected (steady state) | Live data updates at 5s (health) and 30s (infrastructure) intervals. Green connection dot. | SignalR push events |
| Reconnecting | Yellow connection dot. Data freezes at last received values. After reconnect timeout (30s max), falls back to polling. | Last cached SignalR data, then React Query polling at 15s |
| Disconnected (polling fallback) | Red connection dot. Data updates every 15s via REST polling. | React Query `refetchInterval: 15000` |
| Reconnected after disconnect | Green connection dot resumes. Polling stops. Fresh data snapshot from `InitialState` event. | SignalR push events |
| Error (API unreachable) | Ant Design Alert banner: error type with message and retry guidance | No data source available |

### Tab-Specific Behavior

All 6 tabs receive data from the same SignalR connection. When SignalR is connected, mock data generators are completely bypassed. The data flow per tab:

| Tab | SignalR Event | Fallback (polling) | Update Frequency |
|-----|--------------|-------------------|------------------|
| Overview | ServiceStatusUpdate, MetricsUpdate | GET /api/v1/health-status | 30s |
| Device Health | DeviceHealthUpdate | GET /api/v1/health-status (existing) | 5s |
| Pods | PodStatusUpdate | None (show stale with timestamp) | 30s |
| Traces | TraceUpdate | None (show stale with timestamp) | 30s |
| Queues | QueueStatusUpdate | None (show stale with timestamp) | 30s |
| Alerts | AlertUpdate | None (show stale with timestamp) | 30s |

## Interaction Contract

### Connection Lifecycle (User-Visible)

1. **Page mount:** Show Spin loader with "Connecting to monitoring hub..." text
2. **SignalR connected + InitialState received:** Hide loader, render all tabs with real data, show green dot
3. **SignalR disconnected (network blip):** Dot turns yellow immediately. After 30s of failed reconnect attempts, dot turns red and React Query polling activates at 15s
4. **SignalR reconnected:** Dot turns green. Polling stops. InitialState snapshot refreshes all data
5. **Page unmount:** SignalR connection closed via `connection.stop()`. isMountedRef prevents stale state updates

### Toast Notifications

Use Ant Design `message` API (already used for NAS auto-test in Phase 13):

| Event | Type | Duration |
|-------|------|----------|
| Connection lost | `message.warning` | 5 seconds |
| Connection restored | `message.success` | 3 seconds |

No toast on initial connect (green dot is sufficient). No toast on reconnecting state (yellow dot is sufficient).

### No Destructive Actions

This phase is read-only monitoring. No destructive actions, no confirmation dialogs, no delete operations.
