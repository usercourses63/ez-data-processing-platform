    5. **Per-field colored borders (D-13 -- CRITICAL):** Each Form.Item in required tabs must get its own individual colored left border: red for required-empty, green for filled, gray for optional. Do NOT use tab-level uniform borders -- D-13 explicitly requires per-field status.

       **Implementation approach:** Create a helper function `wrapTabWithFieldBorders` that takes a tab key and uses `getFieldStatus` to wrap each field. Since tab components are lazy-loaded and we cannot modify them directly, use this CSS-based approach:

       a. For each required tab pane in the Tabs items array, wrap the tab component in a container div with a `data-tab-key` attribute:
       ```tsx
       {
         key: 'basic',
         label: ...,
         children: (

       ```

       b. Create a `useEffect` that runs after each recalculate (depend on `completeness` state) to inject per-field border styles via DOM data attributes. For each required tab that is currently rendered (visible in DOM):
       ```typescript
       useEffect(() => {
         // For each required tab, find its container and set per-field borders
         for (const tabKey of REQUIRED_TABS) {
           const container = document.querySelector(`[data-tab-key="${tabKey}"]`);
           if (!container) continue;

           const config = TAB_FIELD_CONFIG[tabKey];
           if (!config.fields) continue;

           for (const field of config.fields) {
             // Ant Design Form.Item with name="fieldName" creates element with id="form_fieldName" or similar
             // Find the .ant-form-item that contains the field
             const formItem = container.querySelector(`[class*="ant-form-item"]:has([id*="${field.name}"])`)
               || container.querySelector(`[data-field-name="${field.name}"]`);
             if (!formItem) continue;

             const status = getFieldStatus(tabKey, field.name);
             (formItem as HTMLElement).setAttribute('data-completeness-status', status);
           }
         }
       }, [completeness]);
       ```
