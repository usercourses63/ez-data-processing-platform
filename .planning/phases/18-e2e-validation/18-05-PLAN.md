DataSource API (port 5001):
- GET /api/v1/datasource — returns array of DataSource objects with OutputDestinations
- Each DataSource has: ID, Name, InputServerId, OutputDestinations[]
- OutputDestination has: Name, Type ("folder"|"kafka"|"nas"), OutputServerId, FolderConfig, KafkaConfig, Enabled

Scheduling API (port 5004):
- POST /api/v1/datasources/{dataSourceId}/schedule — creates/triggers polling schedule
- PUT /api/v1/datasources/{dataSourceId}/schedule — updates polling interval
- POST /api/v1/datasources/{dataSourceId}/resume — resumes paused schedule

DemoDataGenerator output destinations:
- Kafka topic (type "kafka") — always JSON, topic named "{datasource-name}-validated"
- NAS/folder archive (type "nas" or "folder") — original format, path pattern includes /archive/{name}
- FTP export (type "folder" on FTP server) — CSV conversion for partners

```typescript
/**
 * Get all data sources
 */
export async function getDataSources(
  request: APIRequestContext
): Promise<any[]> {
  const response = await request.get(`${EZ_API_BASE}/api/v1/datasource`);
  if (!response.ok()) {
    const body = await response.text();
    console.error(`[ez-api] GET /api/v1/datasource failed (${response.status()}): ${body}`);
    throw new Error(`Failed to get data sources: ${response.status()} ${body}`);
  }
  return response.json();
}
```
