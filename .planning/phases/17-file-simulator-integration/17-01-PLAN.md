Implement:

1. `public async Task UploadFilesAsync(List<AdminServer> servers, List<NasDevice> nasDevices, CancellationToken ct = default)`

Logic:
- **For each AdminServer where `server.CanBeInput` is true:**
  - Skip if `server.ServerType == "kafka"` (print skip message: `"  - Skipping {server.Name}: Kafka is not a file protocol"`)
  - Get connector: `var connector = _connectorFactory.GetConnector(server) as IServerConnector;` — skip if null
  - Resolve credentials from `server.TypeSpecificConfig` BsonDocument:
    ```csharp
    var creds = new ServerCredentials
    {
        Username = server.TypeSpecificConfig?["Username"]?.AsString,
        Password = server.TypeSpecificConfig?["Password"]?.AsString
    };
    ```
    For S3: also set `creds.AccessKey = server.TypeSpecificConfig?["AccessKey"]?.AsString` and `creds.SecretKey = server.TypeSpecificConfig?["SecretKey"]?.AsString`
  - Get file manifest from `_fileGenerator.GetFileManifest(4)` — 4 files per server
  - For each file spec `(schemaIndex, recordCount, isJson)`:
    - Generate content: `isJson ? _fileGenerator.GenerateJsonContent(schemaIndex, recordCount) : _fileGenerator.GenerateCsvContent(schemaIndex, recordCount)`
    - Build filePath: `$"{server.BasePath ?? ""}/demo-{schemaIndex:D2}-{recordCount}r{(isJson ? ".json" : ".csv")}"`
    - Call `await connector.WriteFileAsync(server, creds, filePath, content, ct)`
    - Print: `"  Uploaded: {filePath} ({content.Length} bytes) to {server.Name}"`
  - Wrap each file upload in try/catch, print warning on failure, continue to next file
  - Print summary per server: `"  {uploadedCount}/{totalCount} files uploaded to {server.Name}"`

- **For each NasDevice where `nasDevice.Role == NasDeviceRole.Input || nasDevice.Role == NasDeviceRole.Both`:**
  - If `_apiClient == null`: print `"  - Skipping NAS {nasDevice.Name}: no API client for REST upload (NFS mounts not available from host)"` and continue
  - Get file manifest (4 files per NAS device)
  - For each file spec, upload via REST API:
    ```csharp
    var request = new { FilePath = $"/{nasDevice.ExportPath?.TrimStart('/')}/demo-{schemaIndex:D2}-{recordCount}r{ext}", Content = Convert.ToBase64String(content) };
    // NAS devices don't have a serverId for the file operations endpoint
    // Use NasDevice.ID with the NAS-specific write endpoint if available
    // OR skip NAS upload with message explaining limitation
    ```
    NOTE: The FileOperationsController requires an AdminServer serverId, not a NasDevice ID. NAS uploads from outside the cluster are not feasible without a mounted volume. Print: `"  - Skipping NAS {nasDevice.Name}: file upload requires in-cluster NFS mount (upload files manually or from within K8s pods)"`

- Print final summary: `"  Upload complete: {totalUploaded} files across {serverCount} servers"`

2. Private helper `ResolveCredentials(AdminServer server)` returning `ServerCredentials?` as described above.
