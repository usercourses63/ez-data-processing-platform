<task type="auto">
  <name>Task 2: Create NAS integration verification script</name>
  <files>scripts/verify-nas-integration.ps1</files>
  <action>
Create PowerShell verification script for NAS device integration.

Script should:

1. **Prerequisites check:**
   - Verify kubectl is available
   - Verify ez-platform namespace exists
   - Verify RBAC resources exist
   - Check if file-simulator cluster is accessible (optional)

2. **API endpoint verification:**
   - Test GET /api/v1/nasdevices (empty list expected initially)
   - Verify endpoint responds with 200

3. **Create test NAS device:**
   - POST to /api/v1/nasdevices with test data:
     ```json
     {
       "Name": "test-nas-device",
       "Host": "file-sim-nas-input-1.file-simulator.svc.cluster.local",
       "Port": 2049,
       "ExportPath": "/data",
       "Role": "Input",
       "StorageCapacity": "1Gi"
     }
     ```
   - Store returned ID

4. **Provision K8s resources:**
   - POST to /api/v1/nasdevices/{id}/provision
   - Check PvCreated and PvcBound in response

5. **Verify K8s resources created:**
   - kubectl get pv test-nas-device-pv
   - kubectl get pvc test-nas-device-pvc -n ez-platform
   - Check PVC status is Bound

6. **Cleanup:**
   - DELETE /api/v1/nasdevices/{id}/provision (deprovision)
   - DELETE /api/v1/nasdevices/{id}
   - Verify PV and PVC deleted

7. **Report results:**
   - Summary of pass/fail for each step
   - Exit 0 if all pass, 1 if any fail

Script structure:
```powershell
#Requires -Version 7.0
param(
    [string]$ApiBaseUrl = "http://localhost:5001",
    [switch]$SkipCleanup,
    [switch]$Verbose
)

$ErrorActionPreference = "Stop"

function Write-Step { param($Message) Write-Host "[$([char]0x2714)] $Message" -ForegroundColor Green }
function Write-Fail { param($Message) Write-Host "[$([char]0x2718)] $Message" -ForegroundColor Red }
function Write-Info { param($Message) Write-Host "[i] $Message" -ForegroundColor Cyan }

# ... implementation ...
```

Include timeout handling for K8s operations (PVC binding can take 30-60s).
