Create NasDevice entity extending DataProcessingBaseEntity with the following fields:

**Required Fields:**
- Name (string, required, max 100) - Display name
- Description (string?, max 500) - Optional description
- Host (string, required, max 255) - NFS server DNS or IP
- Port (int, default 2049) - NFS port

**Role Classification:**
- Role (NasDeviceRole enum: Input, Output, Backup, Both) - How the device is used

**Computed K8s Resource Names:**
- PvName (computed property) - "{Name.ToLower()}-pv"
- PvcName (computed property) - "{Name.ToLower()}-pvc"
- MountPath (computed property) - "/mnt/{Name.ToLower()}"

**Storage Configuration:**
- StorageCapacity (string, default "10Gi")
- AccessMode (string, default "ReadWriteMany")
- ReclaimPolicy (string, default "Retain")
- MountOptions (List of string, default: ["nfsvers=3", "tcp", "hard", "intr"])

**Provisioning Status:**
- IsPvCreated (bool) - Track if PV was created
- IsPvcBound (bool) - Track if PVC is bound
- LastProvisionedAt (DateTime?) - Last provisioning timestamp
- ProvisioningError (string?, max 1000) - Last provisioning error

**Connection Testing (mirror AdminServer pattern):**
- LastConnectionTest (DateTime?)
- LastConnectionSuccess (bool?)
- LastConnectionError (string?, max 1000)

**Helper Methods:**
- SetConnectionTestResult(bool success, string? error) - Updates connection test fields
- SetProvisioningResult(bool pvCreated, bool pvcBound, string? error) - Updates provisioning fields

Create RBAC manifest following OCP best practices from 02-RESEARCH.md:

**ServiceAccount:**
- Name: nas-device-manager
- Namespace: ez-platform

**ClusterRole (nas-pv-manager):**
PersistentVolumes are cluster-scoped, so we need ClusterRole:
- apiGroups: [""]
- resources: ["persistentvolumes"]
- verbs: ["get", "list", "watch", "create", "update", "patch", "delete"]

**ClusterRoleBinding:**
- Binds nas-pv-manager ClusterRole to nas-device-manager ServiceAccount

**Role (nas-resource-manager) in ez-platform namespace:**
PVCs and Deployment updates are namespace-scoped:
- apiGroups: [""]
- resources: ["persistentvolumeclaims"]
- verbs: ["get", "list", "watch", "create", "update", "patch", "delete"]
- apiGroups: ["apps"]
- resources: ["deployments"]
- verbs: ["get", "list", "update", "patch"]

**RoleBinding:**
- Binds nas-resource-manager Role to nas-device-manager ServiceAccount

Include standard metadata:
- Labels: app=ez-platform, component=nas-device-manager, managed-by=ez-platform
- Annotations with creation date

IMPORTANT: Use '---' YAML document separators between resources.
