**UpdateNasDeviceAsync:**
1. Find existing device
2. If not found, return null
3. Update fields from input

**ProvisionNasDeviceAsync:**

6. Return NasDeviceProvisionResult

Handle exceptions and set device.ProvisioningError.

**Endpoints:**

GET /api/v1/nasdevices
- Query param: includeDeleted (default false)
- Returns List<NasDevice>

GET /api/v1/nasdevices/{id}
- Returns NasDevice or 404

GET /api/v1/nasdevices/by-role/{role}
- role: Input, Output, Backup, Both
- Returns List<NasDevice>

POST /api/v1/nasdevices
- Body: CreateNasDeviceRequest
- Returns 201 with created NasDevice

PUT /api/v1/nasdevices/{id}
- Body: UpdateNasDeviceRequest
- Returns updated NasDevice or 404

DELETE /api/v1/nasdevices/{id}
- Soft delete
- Returns 204 or 404

POST /api/v1/nasdevices/{id}/provision
- Body: ProvisionNasDeviceRequest
- Returns NasDeviceProvisionResult
- Creates PV and PVC in Kubernetes

DELETE /api/v1/nasdevices/{id}/provision
- Query param: namespace (default ez-platform)
- Deletes PV and PVC
- Returns 204 or 404

POST /api/v1/nasdevices/{id}/test-connection
- Returns NasDeviceConnectionTestResult

Use Hebrew error messages consistent with ServersController:
- "התקן NAS לא נמצא" (NAS device not found)
- "שגיאה ביצירת התקן NAS" (Error creating NAS device)
