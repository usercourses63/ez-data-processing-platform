    The deep pipeline test validates that a CSV file placed on a source triggers the full cross-service event chain: FileDiscovery detects it, FileProcessor converts it, Validation validates records, and Output delivers results.

    This test requires the file-simulator to be running and a NAS input device to be provisioned. If unavailable, manual verification steps are provided.
  </what-built>
  <how-to-verify>
    **Option A — If file-simulator is running:**
    1. Verify file-simulator is accessible: `curl http://file-simulator.local:30080/health`
    2. Check for a datasource with NAS connection in the list
    3. Place a test CSV on the NAS input: use DemoDataGenerator or manual file placement
    4. Watch service logs for pipeline flow:
       ```
       kubectl logs -f deployment/filediscovery -n ez-platform --tail=20 &
       kubectl logs -f deployment/fileprocessor -n ez-platform --tail=20 &
       kubectl logs -f deployment/validation -n ez-platform --tail=20 &
       kubectl logs -f deployment/output -n ez-platform --tail=20 &
       ```
    5. Trigger a manual poll or wait for scheduled poll
    6. Verify log messages show: FileDiscovered -> FileProcessed -> ValidationCompleted -> OutputDelivered
