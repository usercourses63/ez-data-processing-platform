  <action>
    Create `scripts/verify-ocp-compliance.sh` — a bash script that verifies OCP restricted-v2 SCC compliance against RUNNING pods (not just YAML files), per D-05 and D-07.

    **Script structure (per research architecture pattern):**

    ```
    #!/usr/bin/env bash
    # OCP restricted-v2 SCC Compliance Verifier
    # Verifies running pods in ez-platform namespace against OCP restricted-v2 requirements.
    # Usage: bash scripts/verify-ocp-compliance.sh [namespace]
    # Default namespace: ez-platform
    ```

    **Variables:**
    - NAMESPACE="${1:-ez-platform}"
    - PASS_COUNT=0, FAIL_COUNT=0, WARN_COUNT=0
    - Color codes for PASS/FAIL/WARN output

    **Functions to implement (7 checks + 4 additional):**

    1. `check_security_contexts()` — REQ-1,2,3,7:
       - Get all pods: `kubectl get pods -n $NAMESPACE -o json`
       - For each pod, verify:
         - `spec.securityContext.runAsNonRoot == true` (REQ-7)
         - `spec.securityContext.runAsUser > 0` (REQ-4, Minikube mode)
         - `spec.securityContext.seccompProfile.type == "RuntimeDefault"` or empty (REQ-3)
       - For each container in each pod:
         - `securityContext.allowPrivilegeEscalation == false` (REQ-1)
         - `securityContext.capabilities.drop contains "ALL"` (REQ-2)
       - Use jq for JSON parsing. If jq unavailable, fall back to kubectl jsonpath.
       - SKIP pods with names matching `fluent-bit` (known hostPath exception, note in output).

    2. `check_volumes()` — REQ-5:
       - For each pod, check all volume types.
       - Allowed types: configMap, downwardAPI, emptyDir, persistentVolumeClaim, projected, secret
       - FAIL if any pod uses hostPath, nfs, cephfs, etc.
       - WARN (not FAIL) for fluent-bit pods using hostPath (known exception).

    3. `check_ports()` — REQ-6:
       - For each container, check `containerPort` values.
       - FAIL if any port <= 1024.

    4. `check_image_tags()`:
       - For each container, extract image tag.
       - FAIL if any image uses `:latest` tag.
       - List all images with their tags for audit trail.

    5. `check_image_pull_policy()`:
       - For each container, verify `imagePullPolicy == "IfNotPresent"`.
       - FAIL if `Always` (except for images with digest references).

    6. `check_network_policies()`:
       - Verify `default-deny-ingress` NetworkPolicy exists: `kubectl get networkpolicy default-deny-ingress -n $NAMESPACE`
       - Count total NetworkPolicies. WARN if < 5 (expect ~11).

    7. `check_dockerfiles()`:
       - Check Dockerfiles in `src/Services/*/Dockerfile` and `docker/*.Dockerfile` for USER directive.
       - This is a static file check (not runtime). FAIL if any service Dockerfile lacks USER.
       - Use: `grep -l "^USER" <files>` and compare against expected list.

    **Output format:**
    ```
    ========================================
    OCP Compliance Report - ez-platform
    Date: $(date)
    ========================================

    [CHECK 1/7] Security Contexts
      [PASS] pod/datasource-management-xxx: runAsNonRoot=true, runAsUser=1000
      ...
      [SKIP] pod/fluent-bit-xxx: DaemonSet excluded (requires custom SCC on OCP)

    [CHECK 2/7] Volume Types
      ...

    ...

    ========================================
    SUMMARY
    ========================================
    PASSED: X
    FAILED: Y
    WARNINGS: Z

    Overall: PASS/FAIL
    ========================================
    ```

    **Exit code:** 0 if all checks pass (warnings OK), 1 if any FAIL.

    **Important:**
    - Script must be idempotent — safe to run multiple times.
    - Script must check if kubectl and jq are available at start.
    - Script must verify namespace exists before proceeding.
    - Add a `--help` flag that prints usage.
    - Add a `--json` flag that outputs results as JSON (for CI integration).
    - Make the script executable: add proper shebang line.
