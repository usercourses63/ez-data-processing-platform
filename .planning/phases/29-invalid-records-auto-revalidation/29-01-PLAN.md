<objective>
Implement the backend core of auto-revalidation: SchemaUpdatedEvent, schema versioning on entities, InvalidRecordsService consumer, and bulk revalidation service with rate limiting.

Purpose: When a datasource schema is updated, the system must automatically detect the change, publish an event, and trigger bulk revalidation of all non-ignored invalid records for that datasource. This is the backbone of the auto-revalidation feature (per D-01, D-02, D-03, D-04).

Output: SchemaUpdatedEvent contract, SchemaUpdatedEventConsumer in InvalidRecordsService, RevalidationService with batched processing, schema versioning on entities.
</objective>

    2. Create `RevalidationService.cs` (per D-02, D-04):
       - Inject: `IInvalidRecordRepository`, `IPublishEndpoint`, `ILogger<RevalidationService>`
       - Method `BulkRevalidateByDataSourceAsync(string dataSourceId, string triggeredBy)`:
         a. Query all non-ignored, non-deleted records for dataSourceId using repository
         b. If count == 0, return early with TotalRecords=0
         c. Process in batches of 100 (per D-02):
            ```csharp
            const int batchSize = 100;
            const int delayMs = 1000; // per D-02: 1-second delay between batches
            var records = await _repository.GetByDataSourceAsync(dataSourceId, ignoreIgnored: true);
            var batches = records.Chunk(batchSize);
            foreach (var batch in batches)
            {
                foreach (var record in batch)
                {
                    var json = record.OriginalRecord.ToJson(); // Get original data as JSON
                    // Use same PublishRevalidationRequest pattern from CorrectionService
                    var validationRequest = new ValidationRequestEvent
                    {
                        CorrelationId = Guid.NewGuid().ToString(),
                        Timestamp = DateTime.UtcNow,
                        PublishedBy = $"InvalidRecordsService-BulkRevalidation-{triggeredBy}",
                        DataSourceId = record.DataSourceId,
                        FileName = $"{record.FileName}_REVALIDATED_{DateTime.UtcNow:yyyyMMddHHmmss}",
                        FileContent = Encoding.UTF8.GetBytes(json),
                        FileContentType = "application/json",
                        FileSizeBytes = Encoding.UTF8.GetByteCount(json),
                        HazelcastKey = string.Empty,
                        OriginalFormat = "JSON",
                        IsReprocess = true,
                        OriginalInvalidRecordId = record.ID
                    };
                    await _publishEndpoint.Publish(validationRequest);
                    result.Published++;
                }
                // Rate limiting: delay between batches only if >1000 total records (per D-02)
                if (records.Count > 1000)
                    await Task.Delay(delayMs);
            }
            ```
         d. Log: "Bulk revalidation for datasource {DataSourceId}: {Published}/{TotalRecords} published"

       NOTE: The repository may not have `GetByDataSourceAsync` with ignore filter. If not, add a method that queries `DataProcessingInvalidRecord` where `DataSourceId == dataSourceId && !IsIgnored && !IsDeleted`. Check repository interface first.
