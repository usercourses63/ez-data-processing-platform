Step 1: Update Helm values-local.yaml image tags to v0.3.0.

Check `helm/ez-platform/values-local.yaml` for image tag references. If tags are hardcoded (e.g., `tag: v0.2.0`), update all service image tags to `v0.3.0`. The services are:
- datasource-management, validation, fileprocessor, filediscovery, scheduling, output, metrics-configuration, invalidrecords, frontend, docusaurus

If tags use a global variable like `{{ .Values.global.image.tag }}`, update the global tag to `v0.3.0`.

Step 2: Deploy via Helm.

```bash
helm upgrade --install ez-platform ./helm/ez-platform \
  --namespace ez-platform \
  --create-namespace \
  --values helm/ez-platform/values-local.yaml \
  --wait \
  --timeout 15m
```

Step 3: Wait for all pods to be ready.

```bash
kubectl wait --for=condition=Ready pod --all -n ez-platform --timeout=300s
kubectl get pods -n ez-platform
```

Step 4: Ensure port forwards are running.

```bash
powershell.exe -ExecutionPolicy Bypass -File "scripts/start-port-forwards.ps1"
```

Step 5: Seed the cluster with DemoDataGenerator (if not already seeded).

```bash
cd tools/DemoDataGenerator
dotnet run -- --direct-connection --api-url http://localhost:5001
```

Step 6: Run sanity tests.

```bash
cd src/Frontend
npm run test:e2e:sanity
```

All 11 sanity tests (SANITY-01 through SANITY-11) should pass. If any fail, diagnose and fix.
