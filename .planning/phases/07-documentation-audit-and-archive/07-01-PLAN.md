**Categorization Heuristics (from research):**

1. **ARCHIVE - Session Logs (pattern-based):**
   - Files matching `session-*.md` pattern
   - Files in `docs/planning/Phase-MVP-Deployment/`
   - Files in `docs/planning/InvalidRecords/`
   - Files in `docs/planning/Task-3-Metrics/`
   - Target: `docs/archive/sessions/{YYYY-MM}/`

2. **ARCHIVE - docs/planning/ entire directory:**
   - Per GSD decision: "GSD becomes single source of truth"
   - All files in `docs/planning/` → ARCHIVE
   - Target: `docs/archive/planning/`

3. **ARCHIVE - Root markdown files (23 files):**
   - All .md files in project root EXCEPT: README.md, CLAUDE.md, CHANGELOG.md
   - Target: Move to appropriate `docs/` subdirectory based on content

4. **KEEP - Service/component READMEs:**
   - Files in `src/Services/*/README.md`
   - Files in `src/Frontend/**/*.md`
   - Files in `k8s/**/*.md`
   - Files in `tools/**/*.md`
   - Files in `test-data/**/*.md`
   - These stay in situ (not documentation sprawl)

5. **KEEP - docs/ reference documentation:**
   - Files in `docs/` that are reference guides, architecture docs
   - DOCUMENTATION-INDEX.md must be kept

6. **DELETE - Candidates for review:**
   - Duplicate files (same content, different locations)
   - Files with "old", "deprecated", "backup" in name
   - Mark as DELETE but flag for human verification in Plan 02
