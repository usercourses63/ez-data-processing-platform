Use PowerShell script pattern from research:
```powershell
Get-ChildItem -Path docs/ -Recurse -Filter "*.md" |
  Where-Object { $_.FullName -notmatch "archive" } |
  ForEach-Object {
    $content = Get-Content $_.FullName -Raw
    if ($content -notmatch "^---") {
      $frontmatter = @"
---
last-verified: 2026-02-02
status: current
---

"@
      Set-Content $_.FullName -Value ($frontmatter + $content) -NoNewline
    }
  }
```
