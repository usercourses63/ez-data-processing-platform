<objective>
Consolidate the `release-package/helm/ez-platform-ocp` Helm chart to a single production values file and make it correctly OpenShift restricted-v2 compliant.

Purpose: The chart currently ships three overlapping override files (values-prod.yaml with stale v0.2.0 tags, values-dev.yaml, values-production.yaml) and forces `runAsUser/runAsGroup/fsGroup: 1000` via `| default 1000`, which OpenShift restricted-v2 SCC rejects. This collapses the chart to base `values.yaml` + one `values-production.yaml`, refreshes image tags to `ocp-20260621`, unpins the UID/GID so the SCC assigns them, sets `readOnlyRootFilesystem: false` (images write at runtime), and wires the frontend `docsUrl` config the same way the non-OCP chart does.

Output: A two-file values layout, SCC-compliant deployment templates, frontend docsUrl wiring, and a runnable verification proving the rendered manifests are correct (no cluster needed).
</objective>
