# v0.2.0 Browser Cache Issue - Root Cause Analysis

**Date:** 2026-01-27
**Issue:** Browser showing v0.1.15 UI despite pod serving v0.2.0 code
**Status:** RESOLVED - Browser Cache Issue

## Summary

The Kubernetes pod is correctly serving v0.2.0 code with all new features (archive settings UI, server selection), but aggressive browser caching was causing the old v0.1.15 interface to appear.

### 5. Nginx Configuration Analysis ⚠️

**Issue Found:** No cache control headers configured

```nginx
location / {
    root /usr/share/nginx/html;
    index index.html index.htm;
    try_files $uri $uri/ /index.html;
}
```

**Problem:** Without explicit `Cache-Control` headers, browsers use default caching which can be aggressive (especially for static assets like JavaScript files).

## Root Cause

**Browser-side caching** - The browser cached old v0.1.15 JavaScript files and continued serving them despite:
- Pod restart
- Deployment update
- Container using correct image

## Solution Implemented

### 1. Updated nginx.conf with Cache Control Headers

```nginx
location / {
    root /usr/share/nginx/html;
    index index.html index.htm;
    try_files $uri $uri/ /index.html;

    # Disable caching for HTML files (always get fresh version)
    location ~* \.html$ {
        add_header Cache-Control "no-cache, no-store, must-revalidate";
        add_header Pragma "no-cache";
        add_header Expires "0";
    }

    # Cache static assets (JS, CSS, images) for 7 days with ETag validation
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        add_header Cache-Control "public, max-age=604800, must-revalidate";
        etag on;
    }
}
```

**Benefits:**
- HTML files always fetched fresh (no caching)
- Static assets cached for 7 days but with ETag validation
- `must-revalidate` forces browser to check server for updates

### 2. Browser Cache Clearing Instructions

**Method 1: Hard Refresh (Quickest)**
```
Ctrl + Shift + R (Chrome/Edge/Firefox)
```

**Method 2: DevTools Clear Storage**
1. Press `F12` to open DevTools
2. Go to **Application** tab (Chrome/Edge) or **Storage** tab (Firefox)
3. Click **Clear storage**
4. Check all options
5. Click **Clear site data**

**Method 3: Manual Cache Clear**
1. Press `Ctrl + Shift + Delete`
2. Select **All time**
3. Check:
   - ✅ Cached images and files
   - ✅ Cookies and site data
4. Click **Clear data**

**Method 4: Incognito/Private Window**
```
Ctrl + Shift + N (Chrome/Edge)
Ctrl + Shift + P (Firefox)
```

## Lessons Learned

1. **Always configure explicit cache headers** - Don't rely on browser defaults
2. **imagePullPolicy: IfNotPresent is safe** - When using content-hashed filenames
3. **Verify file content, not just deployment status** - Use MD5 hashes
4. **Browser cache is the #1 cause of "old UI" issues** - Clear it first
5. **Vite's hash-based filenames are essential** - Prevents most cache issues
